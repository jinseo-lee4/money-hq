      Monthly fixed costs

        Take-home % covers CPP, EI and tax. Start near 90% and fix it from your first pay stub. Save % is the part of each week's pay that goes to your goal before you spend.

        Your numbers live only in this browser. Clearing browser data deletes them, so download a backup now and then.

        Sync code: move data without a file

        Your data gets locked with a key you pick, then turned into one long line of text. Paste that text into Money HQ in another browser, type the same key, and your data appears. Without the key the code is unreadable. If you forget the key, the code can't be opened, by you or anyone.
